# OTools 插件 · 中国象棋 `otools-xiangqi`

OTools 独立插件：**中国象棋**——双人对弈 + 名局棋谱排盘 + 自由摆盘，内置完整规则引擎。
纯静态实现（原生 HTML/CSS/JS ES modules），无 npm 依赖、无打包器，`node scripts/build-web.mjs` 拷贝即发布。

![logo](logo.svg)

## 功能

- **对弈**：双人轮流走子，点击选子后高亮全部合法落点；将军/将死/困毙提示；悔棋、重新开始；中文纵线记谱列表随对局滚动；对局进度 localStorage 自动保存，重开页面可恢复；三次重复局面给出提示（简化处理，见下方声明）。
- **电脑对弈（人机模式）**：可选「人机 · 我执红 / 人机 · 我执黑」与三档难度（易/中/难）。内置 AI 引擎（negamax + α-β 剪枝 + 迭代加深 + 吃子优先排序 + 静态搜索，复用规则引擎的走子生成与合法性检测）：易 ≤200ms（深度≤2）、中 ≤500ms（深度≤4）、难 ≤900ms（深度≤6）。轮到电脑时状态栏显示「对手思考中…」并锁定棋盘输入；悔棋一次撤 AI+玩家两步；摆盘「从此局面开局」同样走人机流程。**棋力预期**：入门级搜索 AI，无开局库/残局库，中盘战术视野有限，适合休闲与教学对弈，非引擎强度。
- **排盘**：内置名局棋谱库（见下方清单），首/上一/下一/末/自动播放（三档速度），点击棋谱列表任意着法跳转，最后一步高亮、将军/终局提示，着法注解显示在面板。
- **摆盘**：车马相仕帅炮兵 × 红黑棋子盘 + 删除工具，点击棋盘放置/替换；清空、恢复初始局面；「从此局面开始对弈」带合法性校验（双方有王且在九宫、无照面、士相立足点、兵不过后场、子力数量上限）；当前局面 FEN 显示与复制、FEN 导入。
- **导入 / 导出**：对局 JSON（含逐步中文记谱）经 OTools 宿主桥 `openText/saveText` 读写真实磁盘文件，浏览器中自动退化为文件选择 / 下载；FEN 支持复制与粘贴导入。
- **规则引擎**：车马炮兵帅士相全子力走法（蹩马腿、塞象眼、过河兵、炮打隔子）、送将禁手、照面禁手、将军/将死/困毙判定、中文纵线记谱（前/后/中同线消歧）、标准 Xiangqi FEN 序列化。引擎为纯函数、无 DOM 依赖，可直接被 `node --test` 导入测试。

## 玩法

1. **对弈**：红方先行。点击己方棋子 → 点击高亮圆点/圆圈落子。被将军时会给出提示并将帅标红。对局进度自动保存。在对弈面板顶部选择「人机 · 我执红 / 我执黑」可与电脑对弈（难度仅人机模式显示，可选易/中/难）；玩家落子后电脑自动思考应着，期间棋盘锁定，悔棋一次撤 AI+玩家两步。
2. **排盘**：在右侧选择一局名局 → 用控制条逐着打谱，或点「自动」播放；点击着法列表可跳转到任意局面，注解面板同步显示评注。
3. **摆盘**：选一枚棋子后点击棋盘放置（再次点击同格可替换），选「删除」后点击棋子可移除；校验通过后点「从此局面开始对弈」直接开局（人机模式下同样自动进入电脑对弈流程）。

## 开发

```bash
node --test tests/          # 规则单元 + 记谱 + FEN + 棋谱逐步合法性校验 + AI 引擎测试（全绿）
node scripts/build-web.mjs  # 拷贝 web/ → dist/（唯一构建入口，web 模式）
node scripts/serve-dist.mjs # 本地预览 dist/
```

目录结构：

```
├── plugin.json            # 插件清单（entry: dist/index.html）
├── logo.svg               # 插件图标（象棋主题自绘 SVG）
├── web/
│   ├── index.html         # 入口（保留 OTools 宿主桥 window.otoolsPlugin）
│   ├── css/style.css      # 深色主题样式
│   ├── js/engine/xiangqi.js   # 规则引擎（纯函数，node 可直接 import）
│   ├── js/engine/xiangqi-ai.js # AI 引擎（negamax+α-β+迭代加深，纯函数，node 可直接 import）
│   ├── js/ui/board.js     # Canvas 棋盘渲染
│   ├── js/ui/app.js       # 三页签 UI 逻辑 / 导入导出 / 进度保存
│   └── data/games/index.js    # 内置名局棋谱库
├── tests/                 # node --test 测试（规则/记谱/FEN/棋谱/AI）
└── dist/                  # 构建产物（构建脚本拷贝 web/ 而来）
```

## 棋谱来源与准确性声明

- 古谱两局摘自明代朱晋桢《橘中秘》卷一全局着法，依据公开流传的棋谱资料辑录（现代象棋资料网、象棋古谱整理文章等），**每一着均经本插件内置规则引擎逐步校验合法**，弃马十三着的终局已由引擎判定为重炮将死；巡河十八打收录原谱前十三回合（黑方败势已定）。
- 六局基本杀法演示局按传统杀法定式（马后炮 / 重炮 / 双车错 / 卧槽马 / 天地炮 / 困毙）编排，**逐着经引擎校验为强制杀**：黑方在任何正式回合的每一种应着都无法避免被将死或困毙（测试中做了全应着搜索验证）。
- 遵循「宁缺毋滥」原则：仅收录把握度高、可逐着机械验证的棋局；近代名家实战对局因逐着数据难以可靠考证，暂未收录。
- **规则简化声明**：重复局面第三次出现时仅给出提示、不自动判负；长将 / 长捉判负规则未实现。
